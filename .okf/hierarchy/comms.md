# COMMS — Factory Communication & Event Infrastructure

**Scope:** Factory-wide · **Sovereign:** yes (role 06) · **Primary verb:** transport  
**Authority:** structured event distribution and correlation only.  
**Owns:** event delivery, structured message schema (eventId, correlationId, jobId, actor, floor, type, severity, payload, integrity), observability linkage, cross-floor coordination transport.  
**Does NOT own:** command, capability authorization, spend, repair, verification.  
**Rule:** COMMS CONNECTS THE FACTORY WITHOUT BECOMING ITS COMMANDER. Communication grants no permission.
