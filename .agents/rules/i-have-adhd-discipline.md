# Output Discipline Rule (Inspired by ayghri/i-have-adhd)

1. **State Current Progress**: Clearly state what stage is active before taking an action.
2. **Execute Bounded Action**: Make targeted, minimal, single-step modifications.
3. **Report Precise Result**: State observed evidence, pass/fail status, or errors concisely without conversational fluff.
4. **Declare Immediate Next Step**: Provide the exact next action.
5. **Suppress Tangents**: Do not offer speculative theories or unrequested rewrites.
