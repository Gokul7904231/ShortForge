# Project Ascalon: Cryptographic Provenance & Replay Architecture

## 1. Overview

Operational data used for machine learning must possess end-to-end cryptographic traceability. Without verifiable provenance, it is impossible to determine whether a successful task outcome was generated by a legitimate production worker, an unverified local mock, or corrupted cache state.

---

## 2. Provenance Chain Structure

Every trajectory records a contiguous hash chain linking the original human/overseer intent to the final verified evidence:

```
[Intent Digest] ──► [WorldState Digest] ──► [Decision Payload] ──► [Guardian Lease] ──► [Execution Exit] ──► [Evidence SHA-256]
```

### 2.1 Monotonic Tokens & Fencing
- Distributed workers execute under a leased capability token (`fencingToken`).
- Fencing tokens are strictly monotonically increasing integers.
- Any tool invocation attempted with a stale fencing token is rejected at the capability layer, preventing out-of-order writes or split-brain worker collisions.

### 2.2 Deterministic Identifiers
- Prior implementations utilized unseeded `Math.random()`, producing non-reproducible session identifiers and provenance records.
- Ascalon mandates cryptographically strong UUID generation (`crypto.randomUUID()`) for run-time instances, and content-addressed SHA-256 hashing for input payloads, script texts, audio stems, and output video bundles.

---

## 3. Replay Engine Architecture (`AscalonReplayEngine`)

The `AscalonReplayEngine` ensures that captured trajectories are not static dead logs, but executable simulations:

1. **State Injection**: The initial `worldStateSnapshotId` is loaded into a sandboxed `WorldStateEngine`.
2. **Deterministic Step Execution**: The decision and tool invocations recorded in the trajectory are executed step-by-step against mock or sandboxed environment providers.
3. **Equivalence Verification**: The final state emitted by the replay run is cryptographically compared against the trajectory's `provenance.auditDigest`. If the states differ, the trajectory fails replay validation.
