# OKF Control Plane V2 Verification

Run from repository root:

    python -m unittest tools.okf.tests.test_control_plane -v
    python -m tools.okf.lint
    python -m tools.okf.drift --json-out okf-drift.json

V2 intentionally measures coverage and drift separately from test execution. A verification binding proves that a rule points to a verification artifact; CI evidence determines whether that artifact passes.
