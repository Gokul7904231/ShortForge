## 1. Problem solved

Gstack treats software development as a sequence of specialized roles rather than one generic coding-agent mode.

The repository provides workflow skills spanning planning, architecture review, implementation review, browser QA, security, benchmarking, debugging, design, DevEx, shipping, deployment/canary work, and retrospectives.

## 4. Important boundary

Gstack is a development workflow reference.

It is not:
- FactoryOS authority
- a production orchestrator
- an F00-F07 worker framework
- a replacement for Guardian, AgentRuntime, CAS, F07, or ReleaseAuthorization

Do not import gstack prompt text, hooks, browser assumptions, or runtime architecture as hidden ShortForge policy.

## 5. Browser coexistence

Gstack has its own browser workflow.

ShortForge already has an isolated Chrome DevTools MCP integration. Therefore the canonical ShortForge browser evidence path remains Chrome DevTools MCP over authorized local loopback. Gstack browser skills are the workflow methodology used by Forge Browser, not a second source of browser truth.

## 6. Security boundary

Gstack security workflows are useful for engineering review, but production-helper remains the canonical security evidence station.

The Security Forge combines:
- Semgrep
- Strix
- ZAP
- gstack CSO methodology
- native adversarial tests

Each result retains its own evidence class.
