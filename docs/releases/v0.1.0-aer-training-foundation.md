# ShortForge — AER-Core Training Foundation v0.1.0

**Release channel:** prerelease  
**Tag:** `v0.1.0-aer-training-foundation`

This release marks the engineering foundation for the AER-Core training/evaluation wave.

## Included

- AER-Core typed decision contract and non-authoritative adapter
- Strict decision-output validation
- Verified-gold training contract and export boundary
- Mission/trajectory-isolated dataset preparation
- Reproducible AER-Core trainer
- Validation-only calibration
- Held-out AER-Bench evaluator with measured latency/throughput
- Non-blocking AER-Core shadow coordination beside primary/JEV/GLiDE
- HTTP serving seam for a future trained checkpoint
- Training-boundary CI and source-control exclusion for local datasets/checkpoints
- Ascalon production-golden isolation from synthetic curriculum data
